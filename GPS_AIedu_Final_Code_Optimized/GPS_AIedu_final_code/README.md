# GPS-AIedu / GPS-Agent Final Code Package

This repository contains the finalized code, data-processing utilities, evaluation metrics, tests, and LaTeX paper packages for **GPS-Agent: process control in Vietnamese mathematics tutoring dialogue**.

The project is designed for tutoring mathematics. Main evaluation claims are focused on Socratic **process control** (direct-answer leakage rate, phase validity, GPS completion, and scaffolding pressure/stalls) rather than unvalidated long-term learning gains.

---

## 1. System Architecture & Terminology

The codebase conforms exactly to the terminology used in the paper (`paper/final/main.tex`):

### Evaluation Metrics
- **`direct_answer_leakage`** (`direct_answer_leakage_rate`): Measures direct solutions exposed to the learner.
- **`phase_validity`** (`phase_validity_rate`): Evaluates whether Socratic phases are traversed in the correct order (e.g., Guide $\rightarrow$ Practice before reaching Solve).
- **`gps_completion`** (`gps_completion_rate`): A stricter metric requiring the presence of all three Socratic phases (Guide, Practice, and Solve).
- **`stall`** (`stall_rate`): Scaffolding pressure metric detecting when the student is stuck in consecutive identical phases.
- **`vai`** (Verifiable Autonomy Index): Student autonomy score based on math expressions.

### Data Layers
- **`human_pilot`**: Triangulates tutoring viability using logs from 5 real students across 4 proficiency profiles.
- **`controlled_comparison`**: Controlled simulated learner comparisons (100 sessions per system) for process control statistics.
- **`cross_model_stress_test`**: Dialogue validation using Phi-3-mini to test robustness under model sensitivity.
- **`expanded_exploratory_corpus`**: Large augmented dialogue corpus reserved for diagnostic analysis only.

## 3. Quick Start & Setup

### Python Environment
1. Create and activate a Python virtual environment:
   ```bash
   python -m venv .venv
   # On Windows:
   .venv\Scripts\activate
   # On Unix/macOS:
   source .venv/bin/activate
   ```
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the regression test suite:
   ```bash
   $env:PYTHONPATH="."; python -m pytest -v
   ```
   All 11 tests should pass successfully.

## 4. Main Reproducible Pipelines

Every paper-facing table, figure, and statistical claim is deterministically generated from raw logs using the following scripts.

### Run Full Metrics Pipeline
Generates all figures and LaTeX tables under `reports/full_metrics/`, outputs LaTeX source code under `paper/full_metrics/`, and creates two package ZIP files in the root folder:
```bash
$env:PYTHONPATH="."; python scripts/run_full_metrics_pipeline.py
```
- **`GPS_Agent_Full_Metrics_Overleaf.zip`**: Self-contained LaTeX directory for Overleaf.
- **`GPS_AIedu_Full_Metrics_Package.zip`**: Code and data package for reproducibility.

### Run Final Revision Pipeline
Generates separate layers for the 5-student human pilot, controlled simulated sessions, and cross-model Phi-3 stress tests. Outputs files to `reports/final_revision/` and `paper/final_revision/`:
```bash
$env:PYTHONPATH="."; python scripts/run_final_revision.py
```
- **`GPS_Agent_Final_Revision_Overleaf.zip`**: Contains the revised paper and assets for Overleaf.
- **`GPS_AIedu_Final_Revision_Package.zip`**: Code and data package matching the final revision.

### Run Optimized Pipeline
Fast regeneration of paper assets and Overleaf zip file:
```bash
$env:PYTHONPATH="."; python scripts/run_optimized_pipeline.py
```
- **`GPS_Agent_Overleaf.zip`**: Self-contained LaTeX directory.

### Auditing Tools
Run the question bank answer recovery check:
```bash
$env:PYTHONPATH="."; python scripts/audit_question_bank.py
```

Run the paper text quality/consistency audit:
```bash
$env:PYTHONPATH="."; python scripts/final_paper_audit.py
```

## 5. LaTeX Paper Submission

For Overleaf or paper submission:
1. Download or extract the generated Overleaf ZIP (e.g. `GPS_Agent_Final_Revision_Overleaf.zip`).
2. Upload the zipped file directly to Overleaf.
3. Compile using `main.tex`.
4. *Note on LaTeX compilation*: The package includes a local preview fallback `acl.sty` and `acl_natbib.bst` to compile out-of-the-box. Before final submission, replace these with the official ACL style files provided by the conference venue.
